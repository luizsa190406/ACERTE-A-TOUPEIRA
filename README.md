# Projeto-Programa-o-Web
Repositório dedicado ao projeto da disciplina de Programação Web do 4ª semestre do curso de TADS da UNICAMP

Aqui ficam registradas algumas convenções propostas no desenvolvimento do projeto:
1ª Caso necessário, utilizar apenas imagens sem copyright.
2ª Caso imagens sejam utilizadas. apenas usá-las localmente, sem o uso de links de outros sites, por questão de boas práticas.
3ª Conforme necessário, redimensionar as imagens usando o software G.I.M.P (eu já tenho ele instalado, portanto é só me enviar).
4ª A nomeação de arquivos deve seguir o seguinte padrão: nome em minúsculo e sem uso de espaços, apenas "_".
